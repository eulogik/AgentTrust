# OpenTrustBbench for VS Code

Scan AI agents and MCP servers directly from VS Code.

## Features

- **Scan** any folder for security findings (A–F grade)
- **Trust Card** generation for AI agents and MCP servers
- **Attack analysis** to identify vulnerabilities

## Usage

1. Open the Command Palette (Ctrl+Shift+P / Cmd+Shift+P)
2. Type "OpenTrustBench"
3. Choose: Scan Folder, Generate Trust Card, or Attack Analysis

## Prerequisites

Install the npm package first:
```bash
npm install -g @opentrustbench/cli
```
