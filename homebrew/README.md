# Homebrew Tap for OpenTrustBench

Install OpenTrustBench via Homebrew:

```bash
brew tap eulogik/opentrustbench
brew install opentrustbench
```

Or directly:

```bash
brew install eulogik/opentrustbench/opentrustbench
```

## Usage

```bash
opentrustbench scan ./my-agent
opentrustbench trust ./my-agent
opentrustbench attack ./my-agent
```
